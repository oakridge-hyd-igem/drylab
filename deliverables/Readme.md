# BioChronos Dry Lab Deliverables

**As-of 2026-08-02.** This repository contains the dry-lab deliverables for the M2 v3b-Untagged vs v3b-LVA revision and the DNA-free wet-lab week.

## How to use it
Open `BioChronos_drylab_deliverables_08022026/00_START_HERE/` first. The deliverables index in that folder maps each requested item to the file that answers it; the consolidated report (Revision 2) is the main read.

## Folders
- **BioChronos_drylab_deliverables_08022026/00_START_HERE/** - deliverables index and the consolidated report (Revision 2).
- **BioChronos_drylab_deliverables_08022026/01_M2_v3b_comparison/** - the current M2 comparison: one-page write-up, prediction plots, model code, results, and the model-to-wet-lab mapping table.
- **BioChronos_drylab_deliverables_08022026/02_provenance_audit/** - parameter provenance table (.md and .csv), numerical-audit appendix and figure, citation-verification log, and the supported/inconclusive/contradicted roll-up.
- **BioChronos_drylab_deliverables_08022026/03_DNA_free_week/** - CuSO4 growth-tolerance screen: deliverables memo, 96-well plate layout, and the grounded copper-tolerance anchors.

## Read before use
- Every headline number is a model-conditional prediction, not measured performance of the current sequences. Wet EXP-2 is what turns these into measured values.
- The current M2 comparison is a pBAD/AraC memory test; its leak parameter is pBAD-specific, not the copper-promoter value.
- Seven of the eight requested deliverables are complete. The eighth (a next-iteration proposal) is held until Wet EXP-2 data exist, per the request itself.
- Not part of the requested set: Module 6 (deployment/encapsulation) is not built; the Gold Medal criterion mapping and the novelty determination are team and registration owned.
